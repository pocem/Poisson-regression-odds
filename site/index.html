Elo ratings*

Computed from results with the standard Elo formula; change is since each team's first match this season.

How it works. A bivariate Poisson regression predicts each side's goals from Elo, rolling xG and xGA, points per game and shots-on-target difference. The model is trained once on the last three completed seasons and stays frozen for the whole season; each round only its inputs are updated with the latest results, so this season's form reaches it through Elo, xG, points per game and shots, not through refitting. Its goal predictions are turned into home / draw / away probabilities and scoreline odds.

Forecast column. "Live" means the prediction was logged before kickoff; "backtest" means it was recreated afterwards with the same frozen model and only the data available before that match.

Data: football-data.co.uk (results, stats, Bet365 odds), Understat (xG), fixturedownload.com (fixtures). Bet365's margin is removed proportionally, so its odds and probabilities compare directly with the model's.
